# 记忆分类法则（Classification Rules）v1

> 用途：信息类型 → 唯一载体 归属表。mem_guard / 整理员引擎读取，所有记忆写入先查此表。
> 出处：2026-08-23 跨学科分类法调研（认知科学/图书情报/档案学/分面分类/知识管理）+ Claude Code 分层。

## 核心原则

1. **载体 = 知识形态 + 来源**（不是主题）——主题只进分面标签，不进归属轴。这是根治重复的关键。
2. **SSOT 单一事实单一归属**：每个信息类型只有一个主载体，写入只落一处。
3. **指针非复制**：他处需要 = 加指针（`→ 见 X`），永不复制正文。物理一处、检索多入口。
4. **继承去重**：下层只写增量/例外，不重复上层。

## 生命周期（档案学）

- 现行（高频利用）→ L1 快取（MEMORY/USER）
- 半现行（偶尔利用）→ viking 语义库 / 技能
- 非现行（少用）→ 归档压缩 / 文档区
- 迁移只改"状态"不改"内容"（逻辑一份，物理位阶变）

## 8 条法则速查

1. **唯一归属律**：写入只落主载体，写前先查表。
2. **主从参照律**：指针（`→ 见 X`）而非复制。
3. **生命周期状态律**：高频→L1，低频→L2，迁移不改内容。
4. **价值鉴定律**：写入前判断有无复用价值，定保管期限；会话噪音直接销毁。
5. **知识形态映射律**：事实→fact/viking，规则→USER/文档，做法→技能，教训→决策日志。
6. **主分类轴+分面索引律**：归属主轴唯一，维度打分面标签（仅检索）。
7. **来源原则律**：按来源上下文归聚（哪个项目来→归哪个域），不按主题重抄。
8. **上位类继承律**：下层只写增量/例外。

## 3 种合法参照（不是复制）

- **指针 Pointer**：`→ 见 X` 只写位置不写内容。
- **继承 Inherit**：下层声明"继承 USER.md §N"不重复正文。
- **派生 Derived**：从原始材料外化出的新产物，以"来源"字段关联回原始位置，内容不双写。

## 防重复硬规则

- 写新条目前**先检索既有库**（SECI 去重步骤），命中则不新建。
- 两处出现 >1 段相同正文 = 报警归位（重复审计 lint）。
- 删除留处置记录（曾存在、因何删）。
